# 团队共享知识库

## 目录结构

```
knowledge/
├── products/           # 产品知识
├── projects/           # 项目知识
├── patterns/           # 最佳实践
│   ├── architecture/   # 架构模式
│   ├── frontend/      # 前端模式
│   └── backend/       # 后端模式
└── decisions/         # 架构决策记录
```

## 使用规则

### 知识沉淀
- 完成项目后，将经验沉淀到对应的知识库
- 重要决策记录在 decisions/ 目录
- 最佳实践记录在 patterns/ 目录

### 知识查询
- 遇到问题时，先查询知识库
- 参考已有模式，避免重复造轮子
- 质疑现有方案时，查阅 ADR 决策记录

### 知识维护
- 每月整理一次知识库
- 删除过时内容
- 更新最佳实践
