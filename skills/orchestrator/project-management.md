# 项目管理技能

## 触发场景

当需要以下任务时使用此技能：
- 分解复杂项目
- 制定项目计划
- 任务优先级排序
- 风险评估
- 进度跟踪

## 核心能力

### 1. 任务分解 (WBS)

将大项目分解为可执行的小任务：

```
项目
├── 阶段1
│   ├── 任务1.1
│   └── 任务1.2
├── 阶段2
│   ├── 任务2.1
│   └── 任务2.2
└── 交付物
```

### 2. 优先级矩阵

| 紧急 | 重要 | 行动 |
|------|------|------|
| ✅ | ✅ | **立即做** - P0 |
| ✅ | ❌ | **委托做** - P1 |
| ❌ | ✅ | **计划做** - P2 |
| ❌ | ❌ | **消除** - P3 |

### 3. 风险评估模板

```markdown
## 风险登记表

| ID | 风险描述 | 影响 | 概率 | 优先级 | 应对措施 |
|----|---------|------|------|--------|----------|
| R1 | ... | 高/中/低 | % | P0-P3 | 缓解/转移/接受 |
```
