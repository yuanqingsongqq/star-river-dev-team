# 任务调度技能

## 触发场景

当需要以下任务时使用此技能：
- 协调多个团队成员
- 分配任务
- 跟踪进度
- 处理阻塞
- 整合输出

## 核心能力

### 1. 调度规则

```
任务分配优先级：
1. 根据技能匹配分配
2. 根据当前负载均衡分配
3. 根据依赖关系排序
4. 根据截止日期紧迫度排序
```

### 2. 依赖管理

```markdown
## 任务依赖图

A ──┬── B (A 完成才能开始 B)
 │
 └──── C (A 和 B 都完成才能开始 C)
```

### 3. 阻塞处理流程

```
发现阻塞
   ↓
判断类型
   ↓
需求不清 → 反馈给 PM
设计问题 → 反馈给 Designer
技术难题 → 反馈给 Architect
等待开发 → 反馈给对应开发者
   ↓
记录阻塞原因
   ↓
等待解决
   ↓
继续执行
```

```markdown

### 整体进度
- 总任务数：X
- 已完成：X

- 阻塞：X

### 里程碑状态
| 里程碑 | 状态 | 完成度 |
|---------|------|--------|
| M1 | ✅/🔄/❌ | X% |

### 阻塞任务
| 任务 | 阻塞原因 | 预计解决时间 |
|------|---------|-------------|
| ... | ... | ... |
```
