# UI 设计技能

## 触发场景

当需要以下任务时使用此技能：
- 页面设计
- 组件设计
- 设计系统
- 交互设计
- 设计评审

## 核心能力

### 1. 设计规范模板

```markdown
# 设计规范 - {产品名称}

## 1. 品牌视觉

### 1.1 Logo
[Logo 使用规范]

### 1.2 色彩系统
| 名称 | 色值 | 用途 |
|------|------|------|
| 主色 | #XXXXXX | 按钮、重点 |
| 辅色 | #XXXXXX | 次要元素 |
| 中性色 | #XXXXXX | 文字、边框 |
| 功能色 | #XXXXXX | 成功/警告/错误 |

### 1.3 字体系统
| 类型 | 字体 | 字号 | 字重 |
|------|------|------|------|
| H1 | ... | 32px | 700 |
| H2 | ... | 24px | 600 |
| Body | ... | 16px | 400 |
| Caption | ... | 12px | 400 |

### 1.4 间距系统
- 基础单位：4px
- 间距层级：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

### 1.5 圆角系统
| 级别 | 圆角 | 用途 |
|------|------|------|
| 小 | 4px | 输入框、标签 |
| 中 | 8px | 按钮、卡片 |
| 大 | 12px | 模态框 |
| 全圆 | 9999px | 头像 |

## 2. 组件规范

### 按钮
| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | 实心主色 | 主要操作 |
| Secondary | 描边 | 次要操作 |
| Ghost | 透明 | 辅助操作 |
| Danger | 红色 | 危险操作 |

### 输入框
| 状态 | 样式 |
|------|------|
| Normal | 灰色边框 |
| Focus | 蓝色边框 |
| Error | 红色边框 |
| Disabled | 灰色背景 |

## 3. 动效规范

| 类型 | 时长 | 缓动 |
|------|------|------|
| 微交互 | 150ms | ease |
| 页面元素 | 250ms | ease-out |
| 页面切换 | 300ms | ease-in-out |
```
