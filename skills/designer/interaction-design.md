# 交互设计技能

## 触发场景

当需要以下任务时使用此技能：
- 用户流程设计
- 交互规范
- 原型设计
- 反馈设计
- 空状态设计

## 核心能力

### 1. 用户流程图模板

```markdown
# 用户流程 - {功能名称}

## 流程概述
[一句话描述流程]

## 流程图
```
[开始] → [步骤1] → [判断?] 
                     ↓是      ↓否
                [步骤2A]  [步骤2B]
                     ↓         ↓
                [步骤3] ←────┘
                     ↓
                [结束]
```

## 详细步骤

| 步骤 | 页面 | 操作 | 系统响应 |
|------|------|------|----------|
| 1 | 首页 | 点击按钮 | 跳转详情页 |
| 2 | 详情页 | 填写表单 | 实时验证 |
| ... | ... | ... | ... |

## 边界情况
| 情况 | 处理方式 |
|------|----------|
| 网络断开 | 显示重试按钮 |
| 超时 | 自动保存草稿 |
```

### 2. 反馈设计规范

```markdown
# 反馈设计规范

## 1. 成功反馈
| 场景 | 形式 | 持续时间 |
|------|------|----------|
| 操作成功 | Toast | 3s |
| 保存成功 | Inline 文字 | 持续 |
| 创建成功 | 跳转页面 | - |

## 2. 错误反馈
| 场景 | 形式 | 内容 |
|------|------|------|
| 表单错误 | 输入框下方 | 具体错误信息 |
| 网络错误 | Toast + 重试 | "网络错误，点击重试" |
| 服务器错误 | 全页提示 | "服务器异常，请稍后重试" |

## 3. 加载状态
| 场景 | 形式 |
|------|------|
| 页面加载 | Skeleton |
| 按钮加载 | Spinner |
| 列表加载 | 分页/无限滚动 |

## 4. 空状态模板
```markdown
[图标/插图]

标题：暂无 {内容}
描述：{说明如何开始}

[行动按钮] [行动按钮]
```
```

### 3. 响应式断点

```markdown
| 断点 | 宽度 | 设备 |
|------|------|------|
| xs | < 576px | 手机 |
| sm | 576-768px | 大手机 |
| md | 768-992px | 平板 |
| lg | 992-1200px | 小桌面 |
| xl | > 1200px | 大桌面 |
```
