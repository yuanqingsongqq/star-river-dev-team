# 测试策略技能

## 触发场景

当需要以下任务时使用此技能：
- 制定测试策略
- 编写测试用例
- Bug 分析
- 质量评估
- 回归测试

## 核心能力

### 1. 测试策略模板

```markdown
# 测试策略 - {功能名称}

## 1. 测试目标
[测试要达到的目标]

## 2. 测试范围
- **测试范围**：...
- **不在范围内**：...

## 3. 测试类型

### 3.1 单元测试
- **目标**：覆盖核心业务逻辑
- **覆盖率要求**：≥ 80%
- **工具**：Jest / Vitest

### 3.2 集成测试
- **目标**：验证模块间交互
- **范围**：API 接口、数据库操作
- **工具**：Supertest / Playwright

### 3.3 E2E 测试
- **目标**：验证关键用户路径
- **覆盖率**：核心流程 100%
- **工具**：Playwright / Cypress

## 4. 测试环境
| 环境 | 用途 | 数据 |
|------|------|------|
| DEV | 开发调试 | Mock 数据 |
| TEST | 集成测试 | 脱敏生产数据 |
| STAGING | 预发布验证 | 生产数据副本 |

## 5. 测试数据管理
[测试数据准备和清理策略]
```

### 2. 测试用例模板

```markdown
# 测试用例 - {功能名称}

## TC-001: {测试场景}

### 基本信息
- **用例编号**：TC-001
- **用例标题**：...
- **优先级**：P0 / P1 / P2
- **前置条件**：...

### 测试步骤
| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 输入用户名 | - |
| 2 | 输入密码 | - |
| 3 | 点击登录 | 跳转首页 |

### 边界情况
| 情况 | 输入 | 预期结果 |
|------|------|----------|
| 空用户名 | - | 提示"用户名不能为空" |
| 错误密码 | 123456 | 提示"用户名或密码错误" |

### 关联需求
- REQ-001
```

### 3. Bug 报告模板

```markdown
# Bug 报告 - #{ID}

## 基本信息
| 字段 | 内容 |
|------|------|
| Bug ID | BUG-XXX |
| 标题 | ... |
| 严重程度 | P0(致命) / P1(严重) / P2(一般) / P3(低) |
| 优先级 | 高 / 中 / 低 |
| 发现版本 | v1.0.0 |
| 发现日期 | YYYY-MM-DD |
| 发现人 | ... |

## 复现步骤
1. 打开页面 /api/users
2. 点击"创建用户"按钮
3. 输入邮箱：test@example.com
4. 点击"确定"按钮
5. **实际结果**：显示"邮箱格式错误"
6. **预期结果**：创建成功，跳转用户列表

## 环境信息
- **浏览器**：Chrome 120
- **操作系统**：macOS 14
- **网络**：WiFi

## 截图/录屏
[附件]

## 根因分析
[分析 Bug 产生的原因]

## 修复建议
[建议如何修复]
```
